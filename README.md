## ✨ Overview

**The Daily Circuit** reimagines digital news delivery as an artisanal, finite printed broadsheet combined with cutting-edge web craftsmanship. Built for engineers, researchers, and builders weary of endless feeds and algorithmic doomscrolling, each edition presents a curated, auditable snapshot of artificial intelligence developments, open-weight models, infrastructure post-mortems, and silicon progress.

---

## 🚀 Key Features

### 1. 🤖 Inky Press-Bot (Living Editorial Mascot)
- **60 FPS Physics & Autonomous Locomotion**: Patrols the broadsheet, performs gravity jumps, tosses with momentum, and lands with procedural squash-and-stretch.
- **Context-Aware DOM Perching**: Leaps onto Bento cards, dangles its legs over borders, and delivers contextual insights via speech bubbles (`data-perch="true"`).
- **Double-Click Command Console**: Freezes completely in place when summoned, opening an interactive terminal to answer queries (`summarize`, `top repo`, `signal ratio`, `backflip`, `nap`).
- **Articulated Anatomy & Multi-Props**:
  - Fountain pen ink-nib antenna with glowing filter
  - Real boots/shoes with procedural walking kinematics
  - Magnifying Loupe during benchmark inspections
  - Rubber Stamp during edition completion ceremonies
- **Expressive Optics**: Interactive gaze tracking with white highlights, realistic eyelid blinking, dizzy spirals on rapid pokes, and celebration curves.
- **Synthesized Sound**: 100% code-driven Web Audio API chirps, landing thuds, and victory chimes.
- **3 Visual Styles**: `OBSIDIAN` (hardware stealth), `INK` (high-contrast print), and `RISO` (warm cream & vermilion).

### 2. 🍏 Dynamic Liquid Glass MacBook Notch Navbar
- **Concave Ear Notch Geometry**: True MacBook-style notch extending from the top edge (`top: 0`) with 22px concave curves and rounded corners.
- **Spring Physics Expansion**: Starts in a sleek collapsed digital clock mode and smoothly springs open on click or scroll into full navigation.
- **Integrated 60-Second Audio Brief**: Native HTML5 audio broadcasting engine with real-time audio playback and dynamic equalizer animation.
- **Quick Links**: Fast navigation across `Home`, `3D Mode`, and instant search.

### 3. 📜 8-Page Continuous Miranda Broadsheet
- **Wax Seal Fracture & Manuscript Unroll**: Interactive wax seal cracking with dynamic tension, strain vibration, particle sparks, and cylindrical unroll.
- **8 Dedicated Daily Sections**:
  - **Page 01**: Front Wire & Lead MoE Architecture Teardown
  - **Page 02**: GPU Pricing Ticker & Accuracy Head-to-Head Delta Bars
  - **Page 03**: Production Sev-1 Incident Post-Mortem & Patch Audit Desk
  - **Page 04**: Silicon Accelerator Die Explorer & Packaging Telemetry
  - **Page 05**: Open Source Repository Velocity Leaderboards
  - **Page 06**: Ghost Terminal & Real-Time Code Telemetry
  - **Page 07**: Model Card Audits & Benchmark Contamination Checks
  - **Page 08**: Morning Telegraph Dispatch, Daily Architecture Quiz & "Stamp Complete" Ritual

### 4. ⚡ Responsive Scroll Circuit Path
- **Multi-Strand Bézier Path**: Dynamic high-velocity beam with harmonic echo and glowing particle sparks.
- **Docking Physics**: Remains cleanly docked inside the starting node at scroll `0`, smoothly emerges as the reader travels down, and retracts cleanly on reverse scroll.

## 📦 Getting Started

### Prerequisites
- Node.js 20+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/RaunakxShrivastva/The_Daily_Circuit.git

# Navigate into the project directory
cd The_Daily_Circuit

# Install dependencies
npm install
```

### Development

```bash
# Start local development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
# Type check and build for production
npm run build

# Preview production build locally
npm run preview
```

## 🎮 Mascot Cheat Sheet (Double-Click Inky)

| Command | Action |
| :--- | :--- |
| `backflip` | Performs a 360° mid-air press flip with confetti |
| `jump` / `perch` | Leaps onto a random Bento card |
| `summarize` | Delivers a concise 2-sentence summary of today's edition |
| `top repo` | Reports the highest velocity GitHub repository |
| `signal` | Audits today's signal-to-noise ratio percentage |
| `sleep` / `nap` | Powers down the ink nib and begins snoring with `zZz` particles |
